# Código-fonte

Aplicação web estática (HTML, CSS e JavaScript puro). Para rodar localmente, sirva esta pasta com qualquer servidor estático:

```bash
python3 -m http.server 8000
```

Depois acesse http://localhost:8000. Conta de demonstração: `clovis@admin.com` / `clovis123`.

Veja o [README principal](../README.md) para mais detalhes.
